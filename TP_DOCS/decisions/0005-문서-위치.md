# 0005. 문서 위치 규칙 (TP_DOCS)

- 날짜: 2026-11-19
- 상태: 결정
- 관련: [TP_DOCS/README.md](../README.md)

## 배경

문서가 저장소 루트, 각 서비스 폴더, 구글드라이브, 옵시디언 등에 흩어져 있었다.
기록을 모아 회고·이력서 정리에 쓰기 위해 한곳에서 찾을 수 있게 하고 싶었다.

## 결정

- 여러 서비스에 걸친 공통 문서(DB 설계, 인프라·배포, API 계약, 결정 기록, 회의록, 회고)는 `TP_DOCS/` 에 둔다.
- 서비스 전용 문서(`FRONTEND.md`, `BACKEND.md`, `AI.md`, `BATCH.md`)는 **각 서비스 폴더에 그대로** 두고 `TP_DOCS/README.md` 에서 링크한다.
- `README.md`, `ROOT.md`, `AGENTS.md` 는 저장소 루트에 둔다.
- 저장소에는 마크다운만. xlsx·docx 는 구글드라이브.
- 폴더 이름은 다른 폴더(`TP_*`)와 맞춰 `TP_DOCS` (`docx` 는 Word 파일로 오해될 수 있어 쓰지 않음).

## 고려한 대안

- 서비스 문서까지 모두 `TP_DOCS` 로 이동: 한곳에 모이지만 `TP_FE/CLAUDE.md` 의 `@FRONTEND.md` 같은 AI 도구 참조와 상대 링크가 깨지고, 코드와 멀어져 문서가 낡기 쉬움

## 결과

- `DATABASE.md` 를 루트에서 `TP_DOCS/database/` 로 옮김 (`git mv`)
