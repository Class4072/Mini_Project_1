# 결정 기록

"왜 이렇게 정했는지"를 한 파일에 한 결정씩 남깁니다. 나중에 회고·이력서 정리 때 근거가 됩니다.

## 파일 규칙

- 이름: `NNNN-짧은-제목.md` (번호는 4자리, 순서대로)
- 결정을 바꾸면 기존 파일은 지우지 않고 상태를 `대체됨 (→ NNNN)` 으로 바꾸고 새 파일을 만듭니다.

## 양식

```markdown
# NNNN. 제목

- 날짜: YYYY-MM-DD
- 상태: 결정 / 미결 / 대체됨 (→ NNNN)
- 관련: PR·문서 링크

## 배경
## 결정
## 고려한 대안
## 결과·남은 일
```
