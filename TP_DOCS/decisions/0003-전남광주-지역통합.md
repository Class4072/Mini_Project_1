# 0003. 전남광주 지역 통합 표시

- 날짜: 2026-11-19
- 상태: 결정 (BE 통합 코드 지원 전까지의 임시 구조 포함)
- 관련: PR #6, `TP_FE/src/features/trip-request/tripRequestOptions.js`

## 배경

2026-07-01 전남광주통합특별시가 출범하면서 광주광역시와 전라남도가 하나의 광역 자치단체가 됐다.
카카오맵 라벨도 "전남광주"로 바뀌었는데, 메인 화면에는 "전남"과 "광주"가 따로 표시되고 있었다.
수집된 장소 데이터는 TourAPI 기존 지역코드(전남 38, 광주 5) 기준으로 나뉘어 있다.

참고: https://sateconomy.co.kr/news/view/1065592399130180

## 결정

- FE 화면(지역 버튼·지도 라벨)은 **"전남광주" 하나**로 표시한다 (지역 17개 → 16개).
- 지역 정의에 `areaCodes` 를 두고, 전남광주는 `["38", "5"]` 로 일정 생성 요청에 두 코드를 함께 보낸다.
- 지도 포커스는 광주~무안 사이로 옮겨 통합 지역 전체가 보이게 한다.

## 고려한 대안

- BE `region` 테이블에 통합 지역을 상위 지역으로 추가하고 FE 는 코드 하나만 쓰기: 구조는 깔끔하지만 BE·DB 작업이 필요해 보류

## 결과·남은 일

- BE 가 통합 지역코드를 지원하면 FE 는 `areaCodes` 한 줄만 바꾼다 (코드에 TODO)
- TourAPI 가 지역코드를 통합하는지 확인 필요 (바뀌면 배치 수집·DB 지역코드도 영향)
- 지도 마커 API(`/map/places?regionCode=`)는 코드 하나만 받음 → 전남광주 마커가 필요해지면 BE 요청
